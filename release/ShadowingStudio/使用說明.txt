Shadowing Studio — YouTube 英文跟讀練習
=========================================

【需要的東西】
- Windows 10 / 11
- Chrome 或 Edge 瀏覽器（跟讀的語音辨識只有這兩個支援）
- 麥克風（耳機麥克風效果最好）
- 網路
不需要安裝 Python 或其他程式。

【開始使用】
1. 把整個 ShadowingStudio 資料夾放到任何位置（例如桌面），不要只拿出 exe。
2. 雙擊 ShadowingStudio.exe，會出現一個黑色視窗，並自動開啟瀏覽器。
   如果預設瀏覽器不是 Chrome / Edge，請用 Chrome 或 Edge 開啟：http://localhost:8000
3. 使用期間不要關閉黑色視窗；用完直接關掉它即可。
4. 第一次跟讀時，瀏覽器會詢問麥克風權限，請按「允許」。

【第一次執行可能看到的警告】
- Windows 顯示「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
  （這個程式沒有數位簽章，所以會出現此警告。）
- 防毒軟體或防火牆詢問：請選擇允許。程式只在本機 localhost 執行。

【已附的練習】
lessons 資料夾已附 6 支影片的練習題，打開後按右上角「歷史紀錄」就能看到，
點一下即可載入，不需要 API key 或任何帳號。
之後收到新的 lessons\<影片ID>.json，放進 lessons 資料夾、重新開啟網頁，
也會自動出現在歷史紀錄裡。

【資料夾內容】
- ShadowingStudio.exe  主程式
- index.html           網頁
- lessons\             練習題（文章、單字、題目）。自動產生的也存在這裡
- transcripts\         字幕快取（執行後自動產生）
- api_key.txt          你的 Claude API key（第一次輸入後才會出現）

【新影片：自動產生題目】
任何 YouTube 影片都可以看字幕、跟讀、下載字幕 PDF，不需要任何帳號。

文章、單字與練習題可以在網頁上按「自動產生題目」由 Claude 產生（約 1–3 分鐘），
產生後存在 lessons 資料夾，之後同一支影片直接載入，不會再花錢。

這個功能需要你自己的 Claude API key：
1. 到 https://platform.claude.com/ 註冊帳號（和 claude.ai 聊天帳號不同）。
2. 在 Billing 儲值（依用量計費，一支 30–40 分鐘的影片約 US$0.25）。
   建議同時設定每月花費上限。
3. 在 API Keys 建立一把 key（以 sk-ant- 開頭），複製起來。
4. 第一次按「自動產生題目」時，網頁會請你貼上 key，按「儲存並產生」即可。
   key 只會存在這個資料夾的 api_key.txt，不會上傳到別處。
   之後想換 key：刪除 api_key.txt 再按一次「自動產生題目」。
   請不要把 api_key.txt 分享給別人。

不想申請 API key 也沒關係：可以請提供這個程式的人幫你產生
lessons\<影片ID>.json，放進 lessons 資料夾後重新載入影片即可。
